# Held-out pages

Six extra pages written by hand on Nov 22, 2026, after the free trial rule was added and before any model was run on them. They were written to test that rule on wording it was not built from: free trials phrased without the word "trial", intro prices (a cheap first period, percent off a first box, a cheaper first year) and a paid $5 "trial", which by our labeling rules is not a free trial.

Labels follow the same rules as the main set (see ../LABELING.md). They were fixed before the first run and not edited afterwards.
